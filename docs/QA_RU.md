### Что именно проверяют автоматические тесты

Сохранение финансовых значений двух сценариев, сумма источников и направлений финансирования, подпись долевого вклада инвестора, единая шкала графика выручки, отрицательный результат и формат чисел, постоянно видимые условия прогноза, идентификаторы разделов и якоря, отсутствие вымышленных контактов и статуса регистрации, валидация содержимого и экранирование HTML, согласованность редакции, воспроизводимость сборки.

В публичной сборке проверено отсутствие инвесторского PDF, финансового JSON и инвестиционных значений. Это разделение файлов, а не визуальное скрытие одного блока. Проверены реальные HTTP-ответы локального сервера средствами Node, обработка путей и отсутствие выдачи исходников.

### Браузерные сценарии

Для обеих редакций: размеры страницы, загрузка логотипа, русский язык документа, один основной заголовок, отсутствие внешних запросов и ошибок JavaScript, учёт настройки уменьшения движения.

Для инвесторской версии: основной и расширенный сценарии; результат **−0,03**; изменение потребности до **47,50** при переключении; клавиатурное управление вкладками; видимость существенных условий без раскрытия дополнительных пояснений; раскрытие условий участия; диалог материалов, удержание фокуса, Escape и возврат фокуса; скачивание исходного PDF с проверкой SHA-256; мобильное меню; якорь «Команда» и отступ под шапкой; прокрутка только внутри финансовой таблицы; обе таблицы и пояснения при печати; читаемая версия без JavaScript.

## Граница проверки

Браузеру передан точный автономный HTML через `page.set_content`, со встроенными стилями, JavaScript, логотипом и PDF. Это проверка содержимого страницы и её поведения в Chromium, **не посещение опубликованного сайта**. Проверка локального HTTP-сервера выполнена отдельно средствами Node. Сочетание браузера, реального URL и настроек будущего хостинга ещё требует проверки после развёртывания.

**Не выполнены:** Safari и Firefox; реальные телефоны; удалённый GitHub Actions; отправка коммитов; создание репозитория; работа GitHub Pages; DNS и HTTPS; проверка авторизации хостинга. Скрипт загрузки проверен синтаксически, но не выполнялся с авторизованным GitHub CLI. YAML-проверка не подтверждает выполнение workflow на GitHub.

Ни одно из этих испытаний не является пересчётом финансовой модели, проверкой договорной загрузки, аудитом прав на бренд или полной сертификацией доступности интерфейса.

## Что осталось до внешней публикации

Утвердить редакцию для открытого доступа. Указать действующие контакты компании в `content/site.json`. Создать приватный репозиторий и загрузить проект из авторизованной среды. Для инвесторской версии выбрать и проверить серверное ограничение доступа до выдачи страницы **и документов**. Для публичной версии проверить страницу по фактическому адресу, включая пути к ресурсам и мобильный просмотр.

Полные исходники и PDF предназначены только для приватного репозитория. `noindex` и `robots.txt` не являются аутентификацией. Подготовленный workflow Pages передаёт только `dist-public` и выключен до отдельного подтверждения владельца.

## Воспроизведение

```bash
npm run verify
bash -n scripts/push-private.sh
python tests/browser_check.py --browser /путь/к/chromium --out qa-output
```

Последняя команда требует отдельной установки Playwright и браузера. Без `--browser` используется браузер, установленный средствами Playwright. Машинный отчёт: `browser-results.json`; протокол Node: `unit-tests.txt`.
