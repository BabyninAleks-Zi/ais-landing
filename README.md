## Устройство проекта

Статический сайт на HTML, CSS и JavaScript. Для сборки нужен Node.js 22 или новее; внешних npm-зависимостей, базы данных и серверной части нет.

| Путь | Назначение |
| --- | --- |
| `content/site.json` | Услуги, команда и контакты |
| `content/investor.json` | Программа запуска, проектные направления и финансирование |
| `src/` | Стили и поведение страницы |
| `assets/` | Монограмма AIS |
| `scripts/` | Сборка, локальный просмотр и проверка состава поставки |
| `tests/` | Проверки сайта |
| `.github/workflows/` | Автоматические проверки и публикация |

## Локальный запуск

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run dev
```

Сайт откроется по адресу `http://127.0.0.1:4173/`.

```sh
npm run verify       # проверка JavaScript, тесты и обе редакции сайта
npm run check:clean  # сборка только из файлов репозитория
npm run build:pages  # готовая публикация в dist-pages/
```

Дополнительная сокращённая редакция без инвестиционных разделов собирается командой `npm run build:public` и доступна локально через `npm run preview:public` на порту 4174. Основной сайт публикует полную инвестиционную презентацию.

Браузерные проверки находятся в `tests/browser_check.py`; для них отдельно нужны Python, Playwright и Chromium. Результаты сохраняются в локальной папке `qa-output/`.

## Публикация на GitHub Pages

После отправки изменений в `main` процесс **Deploy AIS website** проверяет проект и публикует содержимое `dist-pages/`. Его также можно запустить вручную во вкладке **Actions → Deploy AIS website → Run workflow**.

В **Settings → Pages → Source** выбран **GitHub Actions**. Дополнительные шаблоны Jekyll или Static HTML и разрешающие переменные не нужны. Адрес сайта остаётся прежним.

Публикация содержит только HTML, CSS, JavaScript, монограмму, страницу 404 и правила индексирования. Для сохранения ранее выданной ссылки та же страница доступна в `/dist-investor/`. Файлы исходников, README, отчёты и резервные копии на сайт не передаются.

## Состав репозитория

Явный список исходников задан в `scripts/source-files.mjs`. Документы Word/Excel/PDF, архивы, резервные копии, исходные экспорты и результаты сборки хранятся локально и исключены из Git через `.gitignore`. В текущей версии репозитория остаются только исходники, проверки и настройки сайта.

PDF-приложение сейчас не используется. Его автоматическая публикация отключена: добавление документов требует отдельного изменения состава поставки.
