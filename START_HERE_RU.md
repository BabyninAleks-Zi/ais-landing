# С чего начать

Для просмотра без установки инструментов откройте `AIS_Investor_Preview.html` из комплекта в обычном браузере. Это полноценный автономный файл; интернет не нужен. Он содержит инвестиционные данные, не является защищённой ссылкой и не должен размещаться открыто без согласования.

Исходный проект находится в папке `ais-landing`. Проверка и локальный запуск с Node.js 22+:

```bash
cd ais-landing
npm run verify
npm run preview
```

Откройте `http://127.0.0.1:4173/`.

Загрузка в GitHub с вашего компьютера после авторизации GitHub CLI:

```bash
bash scripts/push-private.sh BabyninAleks-Zi/ais-landing
```

Скрипт создаёт приватный репозиторий при отсутствии; если уже создан приватный `ais-landing`, использует его. Публикацию сайта не включает. Нужны ваша локальная Git-авторизация и настроенное имя/email автора коммита; никаких токенов передавать в чат не требуется.

Перед внешним выпуском необходимо указать рабочие контакты в `content/site.json`, согласовать публичную редакцию либо выбрать защищённое размещение полной версии. Подробности — в README.md.
