# Режим доступа

Полные исходники, инвесторская сборка, её однофайловое HTML-превью и PDF содержат инвестиционную информацию. Не переводить репозиторий в Public без отдельного решения и удаления закрытых данных из всей истории Git.

`dist-public` — отдельная сборка. Она не содержит инвестиционных таблиц, структуры участия, списка проектных приоритетов или исходного PDF. Это не гарантия согласия владельца на публикацию: прежде необходимо утвердить содержимое и контакты.

`dist-investor` не имеет встроенного пароля. Требуется серверный или платформенный контроль доступа, распространяющийся на HTML и все файлы, включая прямую ссылку PDF. `noindex`, `robots.txt`, имя каталога, скрытые вкладки и клиентский JavaScript не являются такой защитой.

Публичный выпуск выключен по умолчанию и требует ручного запуска плюс двух явных признаков согласования в GitHub Actions. Для публичного workflow установлен минимальный набор прав. Токены и пароли в исходниках не используются.

Локальный сервер слушает 127.0.0.1, обслуживает только готовый каталог и отклоняет запись, скрытые файлы и выход за корень. Он предназначен для просмотра, а не для эксплуатации.

Сайт не отправляет формы, не делает внешних HTTP-запросов, не использует аналитику, cookies или localStorage. `mailto`/`tel` появятся только после предоставления реальных контактов владельцем.
